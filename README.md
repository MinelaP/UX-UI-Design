## 🔑 Login & Authentication System Case Study
**Project:** "Beep Away" Mobile Application
**Scope:** Creating a secure and intuitive entry point for users, focusing on the registration and login journey.

### 📐 The Process: From Wireframe to High-Fidelity
This project demonstrates my ability to plan user flows using low-fidelity wireframes before committing to final visual assets.

* **Wireframing Phase:** I mapped out the core layout for the Splash screen, Login, and Sign-up pages. This allowed for quick iterations on element placement and content hierarchy without the distraction of colors.
* **Visual Design (Hi-Fi):** Transitioned the skeletal structures into a polished UI, featuring a clean "Beep Away" branding, cohesive iconography, and a professional blue-white-red color palette.
* **Form UX:** Designed detailed input states for registration (Name, Surname, Email, Password, Confirmation) including validation screens and "Verify Email" prompts to ensure a smooth user onboarding experience.

### 🛠 Deliverables
* **Splash Screen:** Minimalist design with brand identity.
* **Interactive Login:** Features for password recovery and "Remember Me" options.
* **Comprehensive Sign-up:** Multi-field validation for secure account creation.
* **Verification Flows:** Clear feedback loops (success messages and email verification prompts).
